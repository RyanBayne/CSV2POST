[![WordPress](https://img.shields.io/badge/WordPress-5.0%2B-blue.svg)](https://wordpress.org/)

> Create WordPress posts, pages, and custom post types from CSV data. A powerful data importer with long-term data management, automated updates, and template-based content generation.

---

## Features

- **CSV Import** — Import any properly formatted .csv file
- **Post Creation** — Create posts, pages, and custom post types with no limits
- **Content Templates** — Design post content using WYSIWYG editor with data placeholders
- **Category Management** — Create hierarchical categories or map to existing ones
- **Custom Fields** — Import data as post meta with unique key support
- **Tag Generation** — Import pre-made tags or generate them from data
- **Image Import** — Import images to WordPress media gallery with featured image support
- **Automated Updates** — Schedule-based post updating when source data changes
- **Multi-Project** — Manage multiple import projects simultaneously
- **SEO Support** — Create post meta compatible with popular SEO plugins

---

## Installation

1. Upload the `csv2post` folder to `wp-content/plugins/`
2. Activate the plugin through the WordPress Plugins menu
3. Navigate to CSV 2 POST in the admin menu
4. Upload your .csv file and configure your import project

---

## Quick Start

1. **Upload CSV** — Go to CSV 2 POST → Data Sources and upload your file
2. **Create Project** — Set up a new project linked to your data source
3. **Configure Mapping** — Map CSV columns to post fields (title, content, categories, etc.)
4. **Design Template** — Create a content template using column placeholders
5. **Import** — Run the import to generate posts

---

## Requirements

- WordPress 5.0+
- PHP 7.4+
- MySQL 5.7+ or MariaDB 10.2+
